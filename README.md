## 🚀 Overview
Welcome to my **JavaScript Lab repository**!  

This project is a curated collection of practical exercises developed during the **2025–26 academic year**, focusing on mastering JavaScript fundamentals and real-world web development skills.

It explores how JavaScript powers **interactive, dynamic, and responsive web applications** through hands-on implementation of core concepts like:

✨ DOM Manipulation  
✨ Event Handling  
✨ Form Validation  
✨ JSON Handling  
✨ Mini Web Applications
