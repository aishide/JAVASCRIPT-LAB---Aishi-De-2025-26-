# JAVASCRIPT-LAB---Aishi-De-2025-26-

## Overview
This repository contains practical programs and projects developed during the **JavaScript Lab** for the academic year 2025-26. The practicals cover fundamental and advanced concepts of JavaScript, including **DOM manipulation, event handling, forms, JSON handling, and interactive web applications**.  

The exercises helps to understand **how JavaScript is used to create dynamic, interactive, and responsive web applications**.

---

## Tools Required
- Web Browser (Chrome, Firefox, etc.)  
- Text Editor / IDE (VS Code, Sublime Text, Atom, etc.)  
- Basic knowledge of **HTML, CSS, and JavaScript**  

---

## List of Practicals
| Practical | Description |
|-----------|-------------|
| **Practical 1 – SIT Website** | Basic website using HTML, CSS, and JavaScript. |
| **Practical 2 – Calculator & Shopping Website** | Interactive calculator and a simple shopping website with basic functionalities. |
| **Practical 3 – Grading System** | HTML page that calculates grades based on user input using JavaScript. |
| **Practical 4 – Case Changer & Palindrome Checker** | Programs to convert letter case and check palindrome strings. |
| **Practical 5** | JavaScript exercises covering core concepts. |
| **Practical 6 – String Reverse & Vowel Counter** | Reverses input strings and counts vowels. |
| **Practical 7 – Traffic Signal & To-Do List** | Simulates traffic signal and manages a to-do list dynamically. |
| **Practical 8 – Gym Form** | Form validation using JavaScript. |
| **Practical 9 – Theme Switcher** | Webpage theme switcher (light/dark mode) using JavaScript. |
| **Practical 10 – Schedule Planner & JSON Handling** | Interactive schedule planner with JSON data integration. |
